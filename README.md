## Important CS concept

### Lexical Scoping

The scope of a variable or function is determined by the structure of the program code (compile time). It searches for them first in the current scope, then in the enclosing scope and finally the global scope. This is the most commonly used scoping by programming languages (e.g. C, JavaScript, Java, C++, Python, etc.).
- This makes it easy to debug. 

### Dynamic Scoping
The scope of a variable or function is determined by the most recent function call in a program (runtime). It searches for them first in the current function, then the calling function, and any other functions higher in the stack call. This is rarely used by modern languages and can make it hard to predict the program for debugging purposes.
